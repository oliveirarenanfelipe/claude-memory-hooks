# The brake lives in the shape of the output

**The rule.** When deciding how much an autonomous worker may do, the instinctive
question is *"what should it be allowed to do?"* — which produces a list of
permitted tasks that ages with every new case and is wrong in both directions at
once.

The better question is: **through what path does its output have to pass?**

## Why the permission list fails

A list of allowed actions has to anticipate the situations. It cannot, so it is
either too narrow — blocking legitimate work until someone widens it, repeatedly —
or too wide, which is the state it drifts to because widening happens under time
pressure and narrowing never happens at all.

## What shaping the output looks like instead

Do not enumerate what may be done. Constrain **where the result lands and what it
must carry**:

- writes go to a branch, never to the main line
- anything outward-facing produces a draft, and a person sends it
- destructive operations require a written marker in the command itself
- the result must include the evidence that it worked, or it is not accepted

This scales to situations nobody anticipated, because it constrains the exit
rather than the intent. A worker can be given wide latitude to *decide* while
having a narrow path to *deliver*.

## The second half, and it is what keeps the brake alive

**A protection that charges a toll on whoever is doing the right thing is a tax,
and taxes get removed.** If the guard interrupts routine correct work, it will be
disabled within a week — by someone reasonable, under deadline, with good
justification.

So the design constraint is not only "does it stop the bad case" but **"is it
free in the good case"**. A guard that interrupts once and lets a repeat through
costs one sentence. A guard that blocks every time costs its own existence.

## The two together

Wide latitude to act, narrow path to deliver, and the narrow path must be cheap to
walk when you are walking it correctly. Anything else is either theatre or an
obstacle, and both end the same way.
