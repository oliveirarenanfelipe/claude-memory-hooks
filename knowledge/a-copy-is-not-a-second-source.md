# A copy is not a second source

Two laws, learned the same day, from two different claims that both collapsed
when someone finally went looking for the origin.

## 1. Replication is not corroboration

A figure appears in five files. Re-reading it in the fifth feels like
confirmation — you have now seen it several times, in several places, written
down. It is one source, copied four times. Every copy inherits the original's
error and adds the appearance of independent agreement.

The correct question is never *"how many places is this written?"* but
**"how many independent measurements produced it?"** Usually the answer is one.
Sometimes it is zero.

The specific trap: **your own past self is not a source.** A number you asserted
in a report six weeks ago, quoted back today, is not evidence — it is the same
assertion with a date on it. And once the original working material is gone (logs
rotated, session records expired), there is no longer any way to tell the
difference between something you measured and something you estimated.

## 2. A `measured` tag on an unmeasured number inverts its function

Marking claims as measured, estimated or unverified is a good practice, and it
has a failure mode that is worse than not marking anything: **once the tag
exists, the reader stops evaluating and starts trusting the tag.** A `measured`
stamp on a number nobody measured converts self-report into proof, using
machinery built to prevent exactly that.

If you cannot name the command, the query or the file that produced a number,
it does not carry the tag. Not even if you are fairly sure. *Fairly sure* is what
the other tags are for.

## The practice

Before a number leaves your hands:

1. Name the thing that produced it — the command, the query, the log.
2. If the answer is "a document I wrote", trace it back one more step. Keep going
   until you reach an instrument or you run out of trail.
3. If the trail runs out, the number is not measured. Say what it is instead.

## The cheap detector

**Grep the claimed figure in the material it supposedly came from.** Zero hits
means the number and the evidence were never in the same place — which is a
different, and much more common, situation than the number being wrong.
